# Requirements

## Problem

Patients and visitors may concentrate at Kiosks near the main entrance because they do not know that other Kiosks are available in different areas of the hospital.

## Goal

Help users quickly discover Kiosk locations throughout Songklanagarind Hospital.

## Target Users

- Patients
- Visitors
- Hospital staff

## MVP

1. View all Kiosk locations.
2. Search for a Kiosk.
3. Filter by building and floor.
4. View Kiosk details.
5. View the Kiosk location on a floor map.
6. Show the services/functions available at each Kiosk.

## Future Features

- QR code access
- Kiosk status
- Report a broken/moved Kiosk
- Usage statistics
- Nearest Kiosk
- Admin dashboard

## Not in MVP

- Online queue booking
- Payment
- Indoor GPS
- AI chatbot
- User authentication
